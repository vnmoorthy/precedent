The problem
"For the cost of hundreds of CPU hours but only 2 or 3 minutes of their time, I'm now expected to review this." r/ExperiencedDevs · 1.9K upvotes · 438 comments
  • AI-generated PRs wait ~5× longer for first review
  • The senior who owns payments writes the same comment eleven times
  • Every fresh agent session starts with amnesia
Why nothing fixes it

Suggestions aren't enforcement

  • AGENTS.md / rules files — dropped under context pressure; the model treats them as vibes
  • Review bots (Greptile, CodeRabbit) — catch it after the PR exists, on the reviewer's clock
  • Nobody makes the team's past rulings binding at write time
Precedent

Mine → Remember → Enforce

  • Mine recurring objections from Greptile reviews + GitHub PR threads into typed rulings
  • Remember them in claude-mem — persistent, typed, synced across machines
  • Enforce via a Codex PreToolUse hook: violating patches are DENIED in <14ms, with the original PR cited
  • The agent reads the denial and self-corrects — no human in the loop
