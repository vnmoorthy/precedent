01 · The problem

Generation is instant. Review is not.

Agents now produce most of the code. AI-generated pull requests wait roughly five times longer for a first review, and the burden lands on the one person who cannot refuse it — the code owner.

"For the cost of hundreds of CPU hours but only 2 or 3 minutes of their time, I'm now expected to review this."r/ExperiencedDevs · 1.9K upvotes · 438 comments

Rules files don't hold — a CLAUDE.md is a suggestion the model drops under context pressure. Review bots catch the bug after the PR exists, on the reviewer's clock. Nothing makes the team's past decisions binding at the moment that matters: the write.

02 · The system

Mine. Remember. Enforce.

Recurring review objections are distilled into typed rulings — the rule, its path scope, the PR where it was first made, its recurrence count. Rulings persist in claude-mem as first-class memory, synced across machines. A six-line hook bridges the agent's pre-write event to a local daemon that parses the patch, matches path-scoped rulings, and answers in under fourteen milliseconds. It fails open — a dead daemon never blocks the agent.

03 · Flight proof

Delete the memory. The bug returns.

The system carries its own falsification test. Identical task, identical repo, identical model — the only variable is whether the ruling exists in memory. Machine-classified, not eyeballed.

Memory on

✓ compliant verifyWebhookSignature(req.headers) !alreadyProcessed(external_delivery_id)

Memory off

✗ violates const event = JSON.parse(req.body) // no signature check

The ruling is doing the work, not the model.

04 · Anomaly report

The agent fought the gate. Twice.

The first ruleset produced zero denials. Codex routed around it — once by passing req.body through a parameter rename, and once by defining a decoy function named constructEvent that satisfied the rule's letter while parsing unverified input. Rulings are now decoy-resistant: they demand a qualified call, never a bare identifier. Same task, after hardening: zero to nine denials. If suggestions were enforcement, the agent wouldn't have needed to cheat.

One repo. One hook.

Copy the hook into any repo you want governed, start the daemon, and the team's precedent holds for every agent session that touches it.
